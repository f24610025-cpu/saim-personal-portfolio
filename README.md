# Saim — Personal Portfolio (Web Development Project 01)

A beginner-level single-page portfolio built with HTML5, CSS3 (Flexbox and Grid), and vanilla JavaScript. No React, Bootstrap, Tailwind, or other frameworks.

## How to open locally

1. Open `index.html` in a browser, or
2. Use any static server from this folder (optional).

Google Fonts and Font Awesome load from CDNs, so you need internet for those extras. The page layout still works without them.

## Replace these placeholders


| What                   | Where                                                                                                                      |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Profile photo          | In `index.html`, swap the initials box for `<img src="assets/images/profile.jpg" alt="Portrait of Saim">` and add the file |
| CV PDF                 | Put your file at `assets/cv/saim-cv.pdf`                                                                                   |
| Email                  | Search `your.email@example.com`                                                                                            |
| GitHub                 | Search `GitHub (add URL)` and replace `href="#"`                                                                           |
| LinkedIn               | Search `LinkedIn (add URL)` and replace `href="#"`                                                                         |
| Project text and links | The three cards in the Projects section                                                                                    |


Optional later: in `js/main.js`, set `FORMSPREE_ENDPOINT` to your Formspree URL. The site works without it.

## Tech allowed on this project

- HTML5
- CSS3, Flexbox, CSS Grid
- Vanilla JavaScript ES6
- Google Fonts
- Font Awesome CDN
